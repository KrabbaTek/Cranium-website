# Cranium

This is the website for the Cranium package manager.
Also see the [CLI](https://github.com/KrabbaTek/Cranium-cli) —
it has a lot more information about the package manager.

To save you a trip, I'll provide a quick summary of Cranium:

Cranium is an opinionated package manager for [KrabbaScript](https://github.com/KrabbaTek/krabbascript).
When designing Cranium, my main priority was user experience; I dropped a lot of things
from other package managers that hurt the user experience, such as enforcing a directory structure  
or having unintuitive commands.


On the website, you'll be able to browse and publish packages.

Most of your day-to-day activities can be done through the CLI—
you can even browse packages (to some degree) with it.
